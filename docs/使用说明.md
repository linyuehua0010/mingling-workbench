# 冥零工作台 v2.3.0 · 使用与配置说明

这一版把「装机器人」从一堆手工步骤收进了窗口里：五个组件一键装、人设一键导、求助页的字能改、掉线会用人话叫你。

> 只讲怎么用和怎么配。为什么这么改，见 [CHANGES.md](CHANGES.md)；验收记录见 [ACCEPTANCE.md](ACCEPTANCE.md)。

---

## 1. 装完之后先做一件事：把「机器人根」指对

工作台里有两套目录，很多人第一次会被这里绊住：

| 概念 | 默认 | 装什么 |
|------|------|--------|
| 工作区（workspace） | `文档\冥零工作台` | 看 B 站的产物 `out\`、临时 `tmp\`、日志 `logs\`、台账 |
| 机器人根（base） | 工作区的上一级 | AstrBot、SnowLuma、Breeze、Ollama 这些组件的安装位置 |
| 组件根（bots） | `<工作区>\bots` | **v2.2.0 起推荐**：五个组件统一装这里 |

已经有一台跑着的机器人（比如 `D:\`），就把 `base` 指过去，否则维护页会全红——检测是在 `<base>\bots\` 和老的平铺目录里找的。

**怎么核对**：

```bat
MinglingWorkbench.exe --paths
```

会打出「工作区 / 机器人根 / 组件根 / AstrBot / SnowLuma / Breeze / Ollama」六行绝对路径。对的就往下走，不对就改配置。

**改在哪**：`%APPDATA%\MinglingWorkbench\settings.json`

```json
{
  "workspace": "D:\\MinglingWorkbench",
  "base": "D:\\"
}
```

注意是**双反斜杠**（JSON 转义），或者用正斜杠 `D:/` 也行。

## 2. 一键配置环境（维护页 →「一键自动配置」）

按下之后跑三段，进度条在维护页顶部：

1. **补环境**：Node、ffmpeg、Python、Ollama（检测）、工作区目录、密钥目录；
2. **装组件**：AstrBot、SnowLuma、Breeze、Ollama、bili-whale 依次装到 `<组件根>\<名字>\`；
3. **自设定**：拿 `pack\mingling-pack\pack.json` 把 DeepSeek、QQ 平台、聊天设置、人设配成冥零（见下一节）。

装完 `<组件根>` 下会多出：

```
bots\
  AstrBot\         start.cmd / env.cmd
  SnowLuma\        node.exe / index.mjs / config\
  Breeze\          start.cmd / models\
  Ollama\          ollama.exe / models\
  bili-whale\      package.json / bin\
  start-all.cmd    一键全起
  .setup.json      这次装了什么、成功/失败，排错先看它
```

**手动跑**（不想开窗口、或想换个目标目录）：

```powershell
powershell -ExecutionPolicy Bypass -File tools\auto-setup.ps1 `
  -Workspace "D:\冥零工作区" -Bots "D:\冥零工作区\bots" -Base "D:\冥零工作区"
# 只想装某几个：-SkipOllama -SkipBreeze
# 全跳过、只检查目录：-Force 别加，直接 -SkipAstrBot -SkipSnowLuma -SkipBreeze -SkipOllama -SkipWhale
```

脚本会写两个**用户级环境变量**：`MINGLING_BOTS`（组件根）和 `OLLAMA_MODELS`（模型目录）。这是为了让下次启动不用再问路径——但 `OLLAMA_MODELS` 指到哪，Ollama 就只认哪的模型，跑之前想清楚 `-Bots` 指哪儿。

命令行也能跑一遍看结果：

```bat
MinglingWorkbench.exe --bots-setup
```

## 3. 自设定（维护页 →「自设定」）

这一段就是「一键自动配置」的第三段：前两段把 Node/ffmpeg 和五个组件装好，机器人这时只是「能启动、不会说话」；自设定拿 `pack\mingling-pack\pack.json` 把她**配成冥零**：

1. **DeepSeek 提供商**：在 `provider-sources` 里建/更新 `deepseek`，挑一个模型（`deepseek-flash` 优先）并用 `providers/test` 测通；
2. **QQ 平台**：按 `pack.platform.id`（`冥零`）精确找 `aiocqhttp` 平台；没有才建一个（`ws_reverse_port` 6199，令牌落在 `private\napcat-ws-token.txt`）；后台里有多个又没有同名的**不猜**，直接报错让你选；
3. **聊天设置**：分段回复、`compression.max_turns=30`、安全模式、`computer_use_runtime=none` 等 13 项，按包里写的点路径写；
4. **插件**：装包里带的 10 个插件（源码在 `pack\mingling-pack\plugins\`，从大肥鱼配置包原样拿来），按包开关；没装过就打包上传 `/plugins/install/upload`，有设置就写 `/plugins/config`，开完重载改过的；
5. **长期记忆**：装 `astrbot_plugin_livingmemory`（市场 id `lxfight/astrbot_plugin_livingmemory`），建一个 embedding 提供商（本机 Ollama 的 `bge-m3`，或硅基流动的 `BAAI/bge-m3`），测通后写进插件的 `provider_settings.embedding_provider_id`，再写记忆范围（主人私聊 + 桌宠 + 群各记各的）；
6. **语音**：按 mode 建一路 TTS 提供商（1 Edge / 3 豆包 / 4 本机 Breeze / 5 Breeze 在线），测通再写全局 `provider_tts_settings`；本机 Breeze 会先查 `/v1/voices`，包里要的 `mingling` 音色不在列表就**不写**、报错让你先做声音；
7. **人设**：调 `tools\import-mingling.ps1`，把人设写进 AstrBot 并切成默认；
8. **验收**：调 `tools\diag-config.ps1`，后台/模型/平台/白名单/人设/插件/记忆/语音逐项 CHECK。

**记忆和语音默认是关的**（`pack.memory.default_mode` / `pack.voice.default_mode` 都是 `"0"`）：装的时候没选、`answers.json` 里也没有 `memory` / `voice` 时，这两块只报「没开」，不会乱配。想开就在 `answers.json` 写 `"memory": 1`（或 2）、`"voice": 4`，也可以写成文件：`<base>\private\memory-mode.txt`、`<base>\private\voice-mode.txt`（里面一行数字，改完不用重装，跑 `--only memory` / `--only voice` 就切）。语音 mode 4 要有冥零自己的 Breeze 音色（默认 `mingling`，可用 `answers.breeze_voice` 换名字）；豆包要 `private\volc-app-id.txt` + `private\volc-token.txt`，Breeze 在线要 `private\breeze-key.txt`。
**10 个插件里默认只开 6 个**：clean、memelog、groupimage、resetkeep、signature、video；petlink（要桌宠桥）、breeze_online_tts、seed_audio_tts、sing 只装不开。video 的 ffmpeg 从 `answers.json` 的 `ffmpeg_path` 或 `bots\ffmpeg\bin\ffmpeg.exe` 里找，ASR 目录同理；`{硅基流动key}` 换不到就跳过那个键，不会覆盖后台已有的值。

**先准备三样东西**（都在机器人根 `<base>` 下）：

```
private\backend.txt       username: … / password: …（或者一行 token: …）
private\deepseek-key.txt  纯文本，一行 key
private\owner-qq.txt      主人 QQ（白名单里写成 "<平台名>:FriendMessage:<qq>"）
```

白名单只加不删：原有条目一条不动，只补缺的。默认模型也只在「现在是空的」或加 `-Force` 时才动，免得把你正在用的模型换掉。

**先干跑**（连后台、只报状态、什么都不写）：

```bat
MinglingWorkbench.exe --selfsetup --dry
```

**只跑一块或几块**（`provider` / `platform` / `chat` / `plugins` / `memory` / `voice` / `persona` / `verify`，多个用逗号）：

```bat
MinglingWorkbench.exe --her-op selfsetup provider
MinglingWorkbench.exe --her-op selfsetup plugins,voice
```

**回退**：每次真改之前会自动快照到 `<base>\private\snapshots\before-selfsetup-<时间>.json`（只留最近 20 份），退回用：

```powershell
powershell -ExecutionPolicy Bypass -File tools\self-setup.ps1 -Base <base> -Restore <快照路径>
```

明细在 `<base>\logs\self-setup.log`；`--her-op` 的单次结果另外落在 `<base>\logs\her-op.txt`。

## 4. 功能页：把配置包里默认关着的几样打开

侧栏第 8 页「功能」（键盘 `1`–`9` 切页，`0` 是帮助）。配置包里默认关着的东西都在这一页，点一下就行：

| 开什么 | 说明 |
| --- | --- |
| 桌宠（petlink） | 桌宠和她共用一份人设与聊天记录 |
| 唱歌（sing） | 群里点歌唱歌，要先有 ffmpeg |
| 豆包语音（seed_audio_tts） | 要 `private\volc-app-id.txt` 和 `private\volc-token.txt` |
| 在线 Breeze 语音（breeze_online_tts） | 要 `private\breeze-key.txt`，音色 ID 默认 `voc_u3nxkd5578wc` |
| 长期记忆 | 关 / 本机 bge-m3（Ollama）/ 硅基流动 |
| 语音路线 | 关 / Edge / 豆包 / 本机 Breeze / 在线 Breeze |

点一下只做两件事：把选择写进 `<base>\private\`（`features.txt` 一行 `插件名=1`、`memory-mode.txt`、`voice-mode.txt` 各一行数字），然后自动跑对应的自设定块——插件走 `plugins`，记忆走 `memory`，语音走 `plugins,voice`。真正接上后台的是那一次自设定，所以缺 key、缺音色它会明说，不会乱写。

- 文件优先：`features.txt` 里写了的插件按文件走，没写的按 `pack.plugins.items[].enable`；
- 选豆包语音或在线 Breeze 时，会顺手把对应插件写成开（不用再去点插件那一行）；
- 命令行等价物：`MinglingWorkbench.exe --her-op feature plugin/astrbot_plugin_dafeiyu_petlink/1`、`--her-op feature memory/1`、`--her-op feature voice/4`。

## 5. 冥零的人设（维护页 →「导入冥零人设」）

人设只存在于 **AstrBot** 里（SnowLuma 只管登 QQ，它的配置没有 persona 字段，塞进去下次启动就被覆盖）。

导入器做四件事：

1. 登录 AstrBot 后台，把人设写进 `personas` 表（同 id 更新，没有就新建）；
2. 把 `agent_runner.config.persona.persona_id` 切成新人设（不切不生效）；
3. 白名单条目 `"旧名字:FriendMessage:<qq>"` 的前缀换成新名字；
4. 同一份正文写到 `<Base>\tools\pet-persona-mine.txt`，桌宠共用。

**准备登录**：`<Base>\private\backend.txt` 写两行

```
username: 你的后台账号
password: 你的后台密码
```

不想存密码就换成一行令牌：

```
token: eyJhbGciOi...
```

（令牌可以用后台配置里的 `dashboard.jwt_secret` 自己签：HS256，payload `{"username":"…","exp":…}`。）

**手动跑**：

```powershell
# 模板还是空的，先预览
powershell -ExecutionPolicy Bypass -File tools\import-mingling.ps1 -DryRun

# 已经有一份写好的整篇人设，直接用它
powershell -ExecutionPolicy Bypass -File tools\import-mingling.ps1 `
  -PersonaFile "D:\\dafeiyu-config-pack\persona\大肥鱼.md"
```

`-DryRun` 只在 `<Base>\logs\mingling-persona.filled.md` 落一份成品给你看，不碰后台。

**想改成自己的角色**：填 `plugin\mingling_skill\persona\mingling.md` 里的 `{user_persona}`（她是谁）和 `{user_tone}`（她怎么说话）；或者复制 `mingling-persona.sample.json` 到 `<Base>\private\mingling-persona.json` 再填。

**导入成功但聊天还是旧人设**：重启 AstrBot（维护页「重启大脑」）。

## 6. 求助页的字可以改成你的（求助页 → 每张卡「改文字」）

11 张卡片，每张下面都有「改文字」和「复制这句」：

- 点「改文字」弹一个多行输入框，写你自己的话，**保存**就落盘；**留空**保存 = 恢复默认那句；**取消/点空白** = 不改。
- 「复制这句」复制的是改过之后的正文，粘到 DeepSeek Harness 里发给 Agent 就行。

改的内容存在 `settings.json` 的 `custom_help_texts` 里：

```json
{
  "custom_help_texts": {
    "role": "换我自己的角色：名字叫……，性格是……",
    "voice.title": "换个更温柔的声音"
  }
}
```

键名 = 卡片 id，11 个 id 依次是：

| id | 卡片 |
|----|------|
| `role` | 换成我自己的角色 |
| `voice` | 换个声音 |
| `breeze` | 换成 Breeze 在线版 |
| `dialect` | 听懂更多方言 |
| `group` | 让她进我的 QQ 群 |
| `silent` | 她不回话了 |
| `always` | 电脑关机她也在线 |
| `napcat` | QQ 升级后先换成 NapCat |
| `backup` | 用备份还原 |
| `uninstall` | 卸载她 |
| `memory` | 记忆没接上 |

- 只写 `<id>` = 改正文；
- 写 `<id>.title` = 连标题一起改。

这个键是**对象**，和别的扁平键不一样；工作台对 `settings.json` 是「原文编辑」，不会因为不在白名单就把你手写的键抹掉。

## 7. 帮助页：组件路径与状态从哪来

帮助页正文的「当前路径」一节现在会列出：

```
工作区 / 台账 / 状态 / 组件根 / AstrBot / SnowLuma / Breeze / Ollama
```

按钮区多了「组件目录」，直接打开 `<组件根>`。

**状态检测**（维护页 8 张卡）的顺序是：先 `<组件根>\<名字>\`，再老的平铺目录（`<Base>\astrbot`、`<Base>\SnowLuma`、`<Base>\breeze-tts`、`<Base>\Ollama`）。所以：

- 新装的（bots 布局）和老装的（平铺）都能认；
- 两个地方都装了同一组件时，**bots 下的优先**。

## 8. 掉线提醒（维护页能开，也能自己配文案）

后台常驻一条心跳，默认 **每分钟**看一次 SnowLuma（5099）、AstrBot（6199）、Breeze（8137，只有本机语音在用的时候才盯）：

- 连着两次没起来才算掉线（避免重启瞬间误报）；
- 同一条 10 分钟内只提醒一次；
- 提醒有两个形态：**右上角滑动横幅**（点里面「重启一下」就直接拉起来）和**托盘气泡**（带自定义头像）。Windows 11 上气泡偶尔不弹，所以横幅是主路径。

**改文案**：`settings.json`

```json
{
  "notify_title": "冥零 · 掉线提醒",
  "notify_body": "哎呀，{name} 掉线了，快重启一下大脑吧~",
  "notify_avatar": "D:\\MinglingWorkbench\\art\\avatar.png",
  "notify_every": "60"
}
```

- `{name}` 会被换成组件名，`{time}` 换成时间；
- `notify_every` 单位秒，钳在 30–600；
- `notify_avatar` 留空就用界面里那张头像；
- 想让提醒**彻底闭嘴**：建一个空文件 `<Base>\private\qq-watch-off.txt`。

维护页的 `watch_on / watch_off / 试一条` 走的是同一套开关。

## 9. settings.json 全键表

| 键 | 值 | 说明 |
|----|----|------|
| `workspace` | 路径 | 工作区（产物/日志/台账） |
| `base` | 路径 | 机器人根 |
| `botRoot` | 路径 | 组件根，默认 `<workspace>\bots` |
| `secrets` | 路径 | 密钥目录，默认 `<base>\secrets` |
| `notify_every` | `"60"` | 心跳间隔（秒，30–600） |
| `notify_title` | 文本 | 提醒标题 |
| `notify_body` | 文本 | 提醒正文，支持 `{name}` `{time}` |
| `notify_avatar` | 图片路径 | 气泡/横幅头像 |
| `mirror_node` | URL | Node 下载镜像 |
| `mirror_ffmpeg` | URL | ffmpeg 下载镜像 |
| `custom_help_texts` | 对象 | 求助页改过的卡片文字 |

前三个路径可以写 `F:/...`，读出来会自动归一成反斜杠。

## 10. 常见问题

**维护页全红，但机器人明明在跑**
`base` 没指对。跑 `--paths` 看「机器人根」是不是你的真实安装位置。

**一键配置说装好了，但路径还是老的**
`auto-setup.ps1` 会写用户级 `MINGLING_BOTS`，它**优先于** `settings.json` 的 `botRoot`。用 `--paths` 的「组件根」核对，错了就把那个环境变量删掉重跑，或者启动前先改它。

**导入人设说「后台没登录上」**
`<Base>\private\backend.txt` 不存在或账号不对。写用户名密码，或写一行 `token:`。

**中文变成问号**
导入脚本里已经处理过（发 UTF-8 字节、收原始字节自己解）。自己写 PowerShell 调后台时别用 `Invoke-RestMethod` 直接发字符串 body。

**托盘气泡不弹**
Windows 11 的通知设置里可能关了这个应用的弹窗；横幅不受影响，点「重启一下」一样能修。

**改了求助页文字，想恢复**
再点「改文字」，清空，保存。

## 11. 卸载与回滚

- 卸载只删**程序**（`%LOCALAPPDATA%\Programs\MinglingWorkbench`），不删工作区里的 `out\tmp\logs`，也不删密钥目录。
- 组件根（`bots\`）里的东西是组件自己的，卸载不会动；不想要了就手动删。
- 人设想退回原来那个：AstrBot 后台「人格」页把默认人设切回去，导入工具只新建/更新，不删旧的。
- 导入人设前的备份在 `<Base>\astrbot\data\cmd_config.json.bak-*` 和 `data_v4.db.bak-*`（如果你手动备份过）。
