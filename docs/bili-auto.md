# API 自动安排 B 站观看

工作台直接使用「B 站 → 配置 → 链接与对话 API」里的 OpenAI 兼容接口，不需要启动 DSH。

1. 填好 Base URL、模型、API Key，点「测一下连接」。测试使用当前表单，不会自动保存。
2. 连接成功后，打开「启用对话 API」并保存。
3. 到「今天看啥」，点「API 安排一轮」：刷新候选、让模型选片和安排时间、逐条观看，成功后调用 API 补充总结。每轮最多三条，也受 `night.maxVideos` 限制。
4. 点「开启自动安排」，以后按 B 站配置的作息窗口和每天最多醒几次运行。模型决定下一次刷新时间，限制为 15–1440 分钟。工作台需保持运行，退出后不执行。
5. 「停止安排」会取消待看任务；正在看的这一条正常完成。观看失败会停止本轮，自动模式至少等待一小时后再安排，且仍受每天次数限制。

任务间至少间隔配置中的 `night.minGapMin`（默认十分钟，上限两小时）；单次计划最多安排到两小时之后。手动安排一轮会立即运行，不受作息窗口限制，但仍计入当天安排次数。失败的安排也计入次数，避免接口故障时持续请求。

任务计划保存在 `<工作区>\logs\bili-plan.json`，观看结果记入同一份 `logs\jobs.jsonl`，来源为 `auto`。重启后正在看的任务标记为中断，不自动重做；超过一天的待看任务取消。自动模式会恢复，未超期的待看任务继续按作息执行。

「换一批」会跳过搜索缓存并排除当前一批；选题同时排除工作台台账中已成功观看的视频。失败时保留上一批，页面展示具体原因。

Base URL 支持接口根地址或完整的 `/chat/completions` 地址，会避免重复拼接路径。API Key 仍只保存在本机密钥文件，不放入任务计划或界面状态。API 会收到选片偏好、候选标题与 UP，以及观看后的文字要点。
