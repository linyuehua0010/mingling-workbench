# 「她会做的事」使用说明

入口：照顾她 → 她会做的事。点开关会自动运行对应的自设定块，等操作结果提示完成再试。

V3.1 起，每项旁边有「配置」按钮，页面下方有四个配置面板。密钥保存后不回显；空白密码框表示保留已存凭据。「保存并使用」会切换到对应路线，「保存设置」只保存，不切换日常语音。

唱歌配置中可切换「豆包云端」「SoulX 本地」，本地目录默认在工作区 `bots/SoulXSinger`。首次使用依次点「部署本地服务」「启动本地服务」「生成本地试听」，试听会生成本机音频。确认后选 SoulX 本地并点「保存并启用唱歌」。本地服务失败时不会自动改用收费的云端方式。

本地默认使用已有冥零参考。要重新应用，点「使用已有冥零参考」；要用已保存的 Breeze `mingling` 音色生成一句新参考，先启动本机 Breeze，在唱歌配置填音色名、地址和中文短句，再点「用已有 Breeze 音色制作唱歌参考」。制作成功后再点「生成本地试听」。这会自动完成时间和音高标注，并备份旧参考。Breeze 合成参考语音，SoulX 生成人声演唱，目前不生成伴奏。

## 桌宠

这个开关启用 QQ 与桌宠的会话互通插件。桌宠使用 DeepSeek Harness（DSH）的 `dsh-pet`，需要先装好桌宠并完成桥接；开启插件后，可以让桌宠接入 QQ 中冥零的大脑、衔接两边的聊天和记忆。

初次接通使用 `tools/setup-pet.ps1 -Dir <工作区>`；检查现有连接加 `-Check`。该脚本还依赖 `astr_setup.py`、`pet_config.py`、`dafeiyu_pet_bridge.py` 等辅助文件，缺文件时需要补齐后再配置。仅打开此开关不会安装桌宠，也不会完成整个桥接流程。

## 唱歌

1. 开启「唱歌」。
2. 在 AstrBot 后台的唱歌插件配置中，默认后端选 `doubao`，填写火山引擎豆包的 APP ID 和 Access Token；已经配置豆包语音提供商时可复用其凭据。
3. 在 QQ 对冥零说「给我唱首生日歌」或「唱首小星星」，等待她发来唱歌语音。

默认使用豆包云端合成，消耗对应服务额度。它会按请求编唱，不保证按原曲旋律演唱。要按谱唱，可另装本地 SoulX 服务，并将插件后端改为 `soulx`。

## 豆包语音

1. 准备火山引擎对应服务的 APP ID 和 Access Token。
2. 在工作区 `private/volc-app-id.txt` 写 APP ID，在 `private/volc-token.txt` 写 Token。也支持在本机 `answers.json` 填 `volc_app_id` 和 `volc_token`。
3. 在下方「语音路线」选择「豆包」。工作台会启用插件并配置语音提供商，等待自设定完成。
4. 在 QQ 里请她发一条语音验证。日常语音出现的频率可在「相处的习惯 → 语音」调整。

仅打开上方「豆包语音」插件开关不会替换当前语音路线。云端合成消耗对应服务额度。

## 在线 Breeze

1. 准备 Breeze 在线服务的 API 密钥和音色 ID。
2. 将密钥放入工作区 `private/breeze-key.txt`；将音色 ID 填入本机 `answers.json` 的 `breeze_voice_id`，格式为 `voc_` 开头。
3. 在下方「语音路线」选择「在线 Breeze」，等待自设定完成。
4. 在 QQ 里请她发一条语音验证。

仅打开上方「在线 Breeze」插件开关不会替换当前语音路线。在线版消耗账号额度；当前使用的「本机 Breeze」在自己的电脑上合成，两者是不同路线。
