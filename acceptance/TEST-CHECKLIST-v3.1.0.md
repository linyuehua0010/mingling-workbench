# 冥零工作台 V3.1.0 手动测试清单（本轮测试包）

> 对应安装包：`MinglingWorkbench-3.1.0-setup.exe`
> 大小 88,855,864 字节；SHA256 `ff9982cd9c45be477f49471a248b93cb7b8c1f28adeaae7b677716f336d809f8`
> 版本 3.1.0（FileVersion 3.1.0.0），**未做代码签名**（SmartScreen 会提示，属预期）。
> 测试环境建议：Windows 11 x64（Win10 也可）、普通用户账号、磁盘剩余 ≥ 12 GB、能上网。

## 0. 准备（2 分钟）

- [ ] 校验安装包：`certutil -hashfile MinglingWorkbench-3.1.0-setup.exe SHA256`
      应等于上面的 SHA256。
- [ ] 记录系统信息：`winver`（版本号）、是否管理员账号、CPU/内存/显卡、所在网络（家用/公司代理）。
- [ ] 准备两个路径，后面要用（**带中文和空格**，例如）：
      - 程序目录：`D:\冥零 测试\程序 3.1`
      - 工作区：　`D:\冥零 测试\工作区 3.1`
- [ ] 若之前装过旧版，先记下旧版的安装目录与工作区，**不要删**（升级测试要用）。

预期中的正常现象，不要当 bug：
- 双击时出现「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」（包未签名）。
- 安装过程无人值守式静默推进，最后可能弹一次组件安装进度窗口。

## 1. 安装：默认路径（第一次）

- [ ] 双击安装包，按默认选项装完。
- [ ] 记下安装器实际使用的程序目录与工作区（安装界面/日志里能看到）。
- **预期**：安装完成，无报错弹窗；开始菜单与桌面出现「冥零工作台」快捷方式；
  双击能打开工作台窗口；窗口标题/关于里版本是 **3.1.0**。
- **重点**：**安装目录里必须有 `MinglingWorkbench.exe`**（不是 `MinglingWorkbench.exe.new.exe`，
  也不是只剩 `.new`）。这是本轮修复的 P0，务必确认。
- [ ] 程序目录下应能看到：`MinglingWorkbench.exe`、`tools\`、`pack\`、`plugin\`、`sidecar\`、
      `skill\`、`docs\`、`unins000.exe`、`WebView2Loader.dll`。

失败时请给我：程序目录截图/文件列表、`<程序目录>\logs\setup\installer-check.log`、
`%TEMP%\finish-update-last.log`（若存在）、安装器窗口里的报错原文。

## 2. 安装：自定义中文 + 空格路径（关键项）

- [ ] 卸载上一份（或换一台干净机器），用命令行安装，把路径换成第 0 步准备的两个中文空格路径：

```bat
MinglingWorkbench-3.1.0-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /CURRENTUSER ^
  "/DIR=D:\冥零 测试\程序 3.1" "/WORKSPACE=D:\冥零 测试\工作区 3.1"
```

- **预期**：
  - [ ] 程序真的装进 `D:\冥零 测试\程序 3.1`（不是 `C:\Users\...\AppData\Local\Programs\...`）。
  - [ ] 工作区真的建在 `D:\冥零 测试\工作区 3.1`，里面有 `bots\`、`logs\`、`private\`、`answers.json`。
  - [ ] 程序目录里**没有** `bots\`（程序与工作区分开）；工作区里**没有** `tools\`
        （工作区里出现 `tools\` 说明装混了）。
  - [ ] 打开工作台，「关于/设置」里显示的工作区就是 `D:\冥零 测试\工作区 3.1`。
  - [ ] 工作台能正常启动、能读配置（不是白屏/报找不到配置）。

失败时请给我：`installer-check.log`、`<工作区>\logs\setup\` 下所有文件、`settings.json` 内容
（`%APPDATA%\MinglingWorkbench\settings.json`）。

## 3. 一键自动配置（装组件，最长 20–40 分钟）

- [ ] 工作台里点「照顾她 → 一键自动配置」（或命令行跑 `tools\bootstrap.ps1`）。
- [ ] 过程中留意窗口/日志里的 `##OK` / `##FAIL` 行，**把整段输出留到最后**（或保留日志文件）。
- **预期**：
  - [ ] `webview2 / node / ffmpeg / uv / python / astrbot / snowluma / breeze / ollama / bots-launchers /
        bili-whale / edge-tts` 这些自动组件显示 OK。
  - [ ] 「QQ 登录 / B站登录 / DeepSeek Key」保持**待人工**，不会自己变成完成。
  - [ ] 结束时最后一行形如 `##RESULT ok=… fixed=… satisfied=… manual=… missing=0 failed=0`；
        `missing`、`failed` 应为 0。有 `failed` 就把对应的 `##FAIL <组件>|原因` 记下来。
  - [ ] 再点一次「一键自动配置」：应该**很快结束**、不再重复下载/重装，输出里全部是「已满足」。
- 慢的是 Ollama（约 1.5 GB）和 python 依赖；如果下载卡住，记下卡在哪个组件。

失败时请给我：`<工作区>\logs\setup\bootstrap-*.log`（最新的那份）、`##FAIL` 原文、网速/代理情况。

## 4. 八块自设定

- [ ] 工作台「照顾她 → 自设定」，或用命令行跑 `tools\self-setup.ps1`。
- **预期**：八块依次为 模型(provider) → 平台(platform) → 聊天(chat) → 插件(plugins) →
  记忆(memory) → 语音(voice) → 人设(persona) → 自检(verify)。
  - [ ] 没填 DeepSeek Key 时，模型块应**明确提示缺少 Key / 待人工**，不能显示「全部成功」。
  - [ ] 填了真实 Key 后，模型块应通过。
  - [ ] 人设写入后，`plugin\mingling_skill\persona\mingling.md` 有内容，工作台里能切到「冥零」。
  - [ ] 最后一行 `##RESULT ok=1 done=8 fail=0`（缺 Key 时允许 provider 明确失败，但要写清原因）。
- 日志：`<工作区>\logs\self-setup.log`。

## 5. AstrBot 真的起来了

- [ ] 打开工作台「服务/日志」页，或命令行看进程：应有 `astrbot.exe` / python 进程在跑。
- [ ] 浏览器打开 `http://127.0.0.1:6185`，能看到后台登录页。
- [ ] 账号密码在 `<工作区>\private\backend.txt`（`url` / `username` / `password`），能登录进去。
- [ ] 工作台「日志」页能看到 `bots\AstrBot\run.log` 的实时内容（不是「日志是空的」）。
- **预期**：端口在听、后台能登录、日志有内容。
- 失败时给我：`netstat -ano | findstr 6185`、`bots\AstrBot\run.log` 最后 100 行、进程列表截图。

  - [ ] 很快结束（不重新下载、不重装组件）。

- **预期**：

  - [ ] 已装好的其他组件不被破坏。
  - [ ] 已下载的缓存还在 `<工作区>\logs\setup\dl\`。
- [ ] 恢复网络后再点一次：应能补装成功。
- [ ] （可选）`tools\bootstrap.ps1 -Offline`：缓存有效时应能装上；缓存被删/被改时应明确失败。

## 13. 已知限制（这些不算 bug，别浪费时间）

1. **安装包未签名**，SmartScreen 会拦一次。
2. **WebView2 缺失分支本轮未验证**：你的机器若本来没装 WebView2，安装器应能装上/提示；
   若失败请单独告诉我，这是本轮唯一没实测过的分支。
3. **本地模型（bge-m3）的 1.1 GB 拉取本轮未实测**（默认安装不含该组件，只有开「本机记忆」才会拉）。
4. **SoulX 本地唱歌**：仍是人工入口（要显卡/CUDA），默认跳过；不要期待「一键全自动」。
5. **真实 QQ 登录、真实 B站登录、真实付费 API** 属外部依赖，需要你本人扫码/充值。
6. QQ/B站/DeepSeek 三项会一直显示「待人工」，这是设计。
