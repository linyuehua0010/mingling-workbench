# 自设定八块：各写什么、怎么验

脚本：`<工作区>\tools\self-setup.ps1 -Base "<工作区>" [-Only <块>] [-DryRun]`
配置包：`<工作区>\pack\mingling-pack\pack.json`（plugins\ 与 voice\ 在同目录）
日志：`<工作区>\logs\self-setup.log`，每行一条；末行是 `##RESULT ok= done= fail= why= next=`。
改之前会先把 `bots\AstrBot\data\` 里的相关文件存一份到 `private\snapshots\before-selfsetup-<时间>.json`。

## provider —— 她用什么模型
- 写 `bots\AstrBot\data\config\` 里的 provider 段；默认留在 `mirarouter/deepseek-v4.1-flash` 不换。
- 换成别家模型时，key 落 `private\deepseek-key.txt`（或对应文件），不要把 key 写进 pack.json。
- 验：`--her-op diag config` 或直接问后台 `/api/v1/provider/get`，别只看日志。

## platform —— 她在哪个 QQ 号上
- 平台名在包里是「冥零」；白名单 12 条（主人 QQ、几个群）。
- 验：后台 6185 上的平台列表里这个平台是「在位」；QQ 侧看 `bots\SnowLuma\snowluma-run.log` 有没有
  `pipe connected`。

## chat —— 怎么说人话
- 13 项：群里回不回、回的时候 @ 不 @、引用不引用、回复分几句、表情包频率、语气……
- 这些项和功能页的「群里回复 / 表情包 / 语音 / 掉线提醒」是同一份数据。

## plugins —— 10 个插件谁开谁关
- 开：petlink（桌宠）、sing（唱歌）、seed_audio_tts（豆包）、breeze_online_tts（在线 Breeze）、
  livingmemory（记忆）、video（看视频）、memelog（表情包）等，按 `private\features.txt` 走。
- 关：不开的行写 `<插件名>=0`。
- 验：`bots\AstrBot\data\plugins\` 里目录在位；开关状态去后台插件列表看，**别看 plugins.json**。

## memory —— 她记不记得住
- 0 关；1 本机 Ollama 的 bge-m3（不花钱，要 `ollama list` 里有 bge-m3）；2 硅基流动（要 key）。
- 写出 `bots\AstrBot\data\config\astrbot_plugin_livingmemory_config.json`，
  并在 `bots\AstrBot\data\plugin_data\astrbot_plugin_livingmemory\` 建目录。
- 验：配置文件的 `mtime` 是刚才；维护页记忆卡片「记住了 N 件事」。

## voice —— 她用什么嗓子
- 0 关；1 Edge（系统音色）；3 豆包（要 appid/token）；4 本机 Breeze（用 `pack\mingling-pack\voice\`
  里给她做的参考音，端口 8137）；5 在线 Breeze（按字扣积分）。
- 验：`bots\Breeze\` 在跑、8137 在听；发一条语音给他听。

## persona —— 她是谁
- 写 `bots\AstrBot\data\` 的 personas，并把这个平台切换成该人设；
  同一份人设同步给桌宠（petlink 读 `private\pet-persona*.txt`）。
- 模板：`plugin\mingling_skill\persona\mingling.md`（`{user_persona}` / `{user_tone}` 两段是他自己的东西）。
- 验：后台 personas 列表里有「冥零」且是默认；问她一句「你是谁」。

## verify —— 跑完自检
- 自检只是把上面几块的「验」做一遍，`-DryRun` 时跳过。
- 出问题先看 `##FAIL <块>|<原因>`，原因里的 `why=` 是给人看的那句。

## 常见失败

| 现象 | 真正原因 |
|---|---|
| `##FAIL 后台｜没登录上` | `-Base` 不是机器人根，`private\backend.txt` 不在它下面 |
| `##FAIL plugins｜pack.json 没找到` | 工作区里没有 `pack\mingling-pack\`，装的时候没带包 |
| memory 块说成功但记不住 | Ollama 没跑 / 没拉 bge-m3；或 livingmemory 插件没装 |
| voice 块说成功但没声音 | 8137 没在听，或 `voice-mode.txt` 被功能页又改回去了 |
